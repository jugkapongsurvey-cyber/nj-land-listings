# NJ Land Listings — หน้าเว็บประกาศที่ดินฝากขาย/ฝากเช่า

เว็บสถิต (static site) ล้วนๆ — ไม่มี build step, ไม่มี backend ของตัวเอง ดึงข้อมูลแปลงที่ดินสดทุกครั้งที่มีคนเปิดเว็บจาก
`https://nj-survey-system.onrender.com/api/public/listings` (endpoint สาธารณะ ไม่ต้อง login)

ตามแผน Phase 2 ("Landing Page นำร่อง") ของ `nj-survey-system/docs/nj-roadmap-survey-to-realestate.md`

## แปลงไหนจะขึ้นเว็บนี้อัตโนมัติ

โอกาสทางธุรกิจ (ในระบบ NJ Survey System) จะขึ้นเว็บนี้ก็ต่อเมื่อครบ **ทั้ง 2 เงื่อนไข**:
1. อยู่ขั้น **"ตกลง/เซ็นสัญญา"** ในบอร์ดโอกาสทางธุรกิจ
2. สถานะหนังสือยินยอม PDPA เป็น **"ได้รับความยินยอมแล้ว"**

ไม่ครบข้อใดข้อหนึ่ง = ไม่ขึ้นเว็บ ไม่มีทางเลี่ยง (ป้องกันเผยแพร่ข้อมูลก่อนได้รับความยินยอมจริง) — ดูโค้ดที่บังคับเงื่อนไขนี้ที่
`nj-survey-system/server.js` route `GET /api/public/listings`

อยากให้แปลงไหนมีคำโปรยสวยๆ ประกอบ ให้เข้าไปที่หน้ารายละเอียดโอกาสทางธุรกิจนั้นในระบบ แล้วกรอกช่อง
"คำโปรยสำหรับหน้าเว็บประกาศ" — รูปภาพดึงมาจากไฟล์แนบของงานรังวัดที่ผูกกับโอกาสนั้นโดยอัตโนมัติ (เฉพาะไฟล์รูปภาพ)

## สิ่งที่ยังต้องทำเอง (นอกเหนือจากโค้ด — ผมทำให้ไม่ได้)

ตามเช็คลิสต์ Phase 2 สัปดาห์ 4 ของแผน:

- [ ] **จดโดเมน** สำหรับเว็บนี้ (เช่น njland.co, njland.th ฯลฯ)
- [ ] **ตั้งค่า Google Business Profile** และ **เพจ Facebook** ของธุรกิจ
- [ ] **หา LINE OA ID จริง** แล้วแก้ค่า `LINE_OA_URL` ใน `app.js` (ตอนนี้เป็นค่า placeholder)
- [ ] ตรวจสอบเบอร์โทร/ที่อยู่บริษัทใน `app.js` (`COMPANY_TEL`, `COMPANY_ADDRESS`) ว่าตรงกับที่ใช้จริง
- [ ] **ยิงงบโฆษณา** Facebook/Google เล็กๆ (~3,000-5,000 บาท) เจาะพื้นที่ที่ที่ดินตั้งอยู่ (สัปดาห์ 6-7 ของแผน)
- [ ] เก็บตัวเลข: จำนวนคนเข้าเว็บ, จำนวนทักไลน์/โทร, จำนวนนัดดูที่ดินจริง — ใช้ตัดสิน**เกณฑ์ผ่าน Phase 2**
      (≥15-20 ลีดใน 30 วัน หรือปิดฝากขายได้จริง 1-2 แปลง ก่อนจะลงทุนสร้างแพลตฟอร์มเต็มรูปแบบใน Phase 3)

## วิธี deploy (เลือกได้ตามที่ถนัด — ไม่มี build step ทั้งนั้น)

เว็บนี้เป็นไฟล์ static ล้วน (`index.html` + `style.css` + `app.js`) ไม่มี build command ให้ตั้ง —
เลือก platform ไหนก็แค่ชี้ไปที่โฟลเดอร์นี้

**Render (แพลตฟอร์มเดียวกับที่ nj-survey-system ใช้อยู่แล้ว — น่าจะง่ายที่สุด)**
1. เข้า Render Dashboard → New + → Static Site
2. เชื่อม repo นี้ (push โฟลเดอร์นี้ขึ้น GitHub repo ใหม่ก่อน)
3. Build Command: เว้นว่าง, Publish Directory: `.`
4. Deploy แล้วผูกโดเมนที่จดไว้ในแท็บ "Custom Domains" ของ service

**ทางเลือกอื่น**: Netlify (ลาก-วางโฟลเดอร์นี้ได้เลย), Vercel, GitHub Pages, หรือ hosting ทั่วไป — วางไฟล์ 3 ไฟล์นี้ที่ document root ก็ใช้งานได้ทันที

## ทดสอบก่อน deploy

เปิด `index.html` ตรงๆ ในเบราว์เซอร์ได้เลย (ไม่ต้องมี local server ก็ได้ เพราะดึงข้อมูลจาก
nj-survey-system.onrender.com โดยตรงผ่าน CORS) แต่ browser บางตัวบล็อก `fetch()` จากไฟล์ `file://`
ถ้าเจอปัญหานี้ให้รันเว็บเซิร์ฟเวอร์เล็กๆ ในโฟลเดอร์นี้แทน เช่น `npx serve .` หรือ `python -m http.server`
