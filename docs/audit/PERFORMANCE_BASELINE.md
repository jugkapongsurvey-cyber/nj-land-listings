## 5. สิ่งที่ทำถูกอยู่แล้ว

| ข้อ | หลักฐาน |
|---|---|
| รูปทุกรูปมี `width` + `height` ในการ์ด และ hero มี `width="2000" height="1126"` | ลด Layout Shift |
| `loading="lazy"` บนรูปการ์ดและรูปเนื้อหา | หน้าแรก 9 จุด |
| hero ใช้ `fetchpriority="high"` และ `<picture>` แยกไฟล์มือถือ | |
| วิดีโอทั้งหมด `preload="none"` | ไม่ดึงไฟล์ 11 MB โดยไม่จำเป็น |
| รูปอัปโหลดมี `cache-control: immutable` อายุ 1 ปี | เข้ารอบสองเร็วมาก |
| ไม่มี third-party script เลย นอกจาก Google Fonts | ไม่มี GTM / jQuery / carousel library |
| Meta Pixel / GA4 โหลดหลังกดยอมรับเท่านั้น | ไม่ถ่วงการโหลดครั้งแรกของคนที่ปฏิเสธ |
| สถิติภายในใช้ `navigator.sendBeacon` | ไม่บล็อกการนำทาง |
| HTML บีบอัดแล้ว (16 KB จาก 54 KB) | GitHub Pages gzip ให้ |

## 8. งานที่ค้างในรายงานฉบับนี้

1. **เก็บค่า Core Web Vitals จริง** (LCP / CLS / INP) ด้วย PageSpeed Insights ทั้ง mobile และ desktop สำหรับ 5 หน้าหลัก — วัดในแผงเบราว์เซอร์ทดสอบไม่ได้

3. **ตรวจ query ฝั่งเซิร์ฟเวอร์** ว่า `/api/public/listings` อ่าน `db.json` ทั้งไฟล์ทุกครั้งหรือไม่ (ฐานข้อมูลเป็นไฟล์ JSON)
4. **วัดบนเครือข่าย 4G จำลอง** ตามที่งานที่ 13 ต้องการ
