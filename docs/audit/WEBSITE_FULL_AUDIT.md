## 3. ปัญหาเชิงสถาปัตยกรรม (สาเหตุรากของงานที่ 1, 2, 6)

### 3.1 มี Design System สามชุดในเว็บเดียว

| ชุด | ไฟล์ CSS | ฟอนต์ | หน้าที่ใช้ |
|---|---|---|---|
| **A — หน้าแรก** | `home.css` (32 KB) | **Sarabun + Trirong** | `index.html` เท่านั้น |
| **B — marketplace** | `marketplace.css` (23 KB) + `warm.css` | **IBM Plex Sans Thai + Manrope** | chat · compare · guides · land · listings · notify · portal · purpose · quote · room · videos |
| **C — ui/style** | `style.css` + `ui.css` (43 KB) | **IBM Plex Sans Thai** | 404 · agency · consign · deal · inspect · partner-apply · tools · verify · wanted |

ผลที่วัดได้จริง

- หน้าแรกใช้ฟอนต์ `Trirong` (serif) สำหรับ H1 ส่วนหน้าอื่นทั้งหมดใช้ `IBM Plex Sans Thai` → **คนที่กดจากหน้าแรกไปหน้าอื่นรู้สึกเหมือนคนละเว็บ**
- CLAUDE.md ระบุเองว่า "หน้าแรกไม่โหลด `marketplace.css` คนละชุดสีกัน โหลดคู่กันแล้วฟอนต์และพื้นหลังตีกัน"
- สไตล์การ์ดประกาศถูกเขียนซ้ำ **สองที่** (`home.css` + `marketplace.css`) เพิ่มคลาสใหม่ต้องแก้สองไฟล์ ลืมที่ใดที่หนึ่ง = อีกหน้าไม่มีสไตล์โดยไม่มี error
- สไตล์แบนเนอร์คุกกี้ `.nj-consent` ถูกเขียนซ้ำ **สี่ไฟล์**: `consent.css`, `home.css`, `inspect.css`, `ui.css`
- ไม่มี design token กลางเลย (ไม่มี `:root` ชุดเดียวที่ทุกหน้าใช้) และหน้าแรกมี inline `style=` **270 จุด**

### 3.2 Header / Footer ถูกคัดลอกลง HTML ทีละหน้า ไม่ใช่ component

ผลคือเมนูหัวเว็บ **ไม่เหมือนกันสักหน้าเดียว** ตรวจพบ **10 รูปแบบ** ใน 21 หน้า

| กลุ่ม | จำนวนเมนู | ตัวอย่างหน้า | ป้ายที่ใช้เรียก "หน้ารวมประกาศ" |
|---|---|---|---|
| หน้าแรก | 11 | index | **ที่ดินประกาศขาย** |
| marketplace เต็ม | 11–12 | listings · land · guides · portal · videos | **ซื้อที่ดิน** |
| ui/style | 9 | consign · verify · wanted · inspect | **แปลงที่ดิน** |
| tools/agency | 9 | tools · agency · 404 | **แปลงที่ดิน** |
| หน้ามีตั๋ว | 8–9 | quote · room · notify | **ดูประกาศทั้งหมด** |

- สิ่งเดียวกันถูกเรียกด้วยชื่อ 4 แบบ → ผู้ใช้จำทางไม่ได้
- ไม่มี **Active State** บนเมนูเลยสักหน้า
- ไม่มี Dropdown / Mega Menu ทุกอย่างเป็นลิงก์แบนเรียงเดียว
- CLAUDE.md เตือนว่าแถวเมนูหน้าแรก "เต็มพอดีแล้ว เติมอีกปุ่มเดียวเมนูจะตัดสองบรรทัดที่จอ 1440" → ยืนยันว่าโครงเมนูปัจจุบันตันแล้วจริง

## 5. สิ่งที่ทำได้ดีอยู่แล้ว (ห้ามรื้อ)

- **ระบบระดับการตรวจสอบ 5 ระดับมีอยู่จริงแล้วใน backend** (`lib/landverify.js`: `owner` → `document` → `site` → `survey` → `transfer`) พร้อมกติกา "ห้ามยกระดับอัตโนมัติ" และ "ผ่านแล้วต้องมีวันที่" ที่มีเทสต์ล็อกไว้ — **งานที่ 7 ไม่ต้องสร้างใหม่ ต้องต่อยอด**
- แยก "ไม่ตรงเงื่อนไข" ออกจาก "ยังไม่ได้ระบุ" ในตัวกรอง พร้อมข้อความบอกจำนวนที่ถูกซ่อน (`#unknown-note`)
- ข้อความปฏิเสธความรับผิดในหน้า `verify.html` เขียนไว้ถูกต้องแล้ว ("ไม่ใช่การรับรองกรรมสิทธิ์") ใช้เป็นต้นแบบให้หน้าอื่นได้
- สถิติภายใน `/api/public/track` ไม่ใช้คุกกี้และไม่มี PII · Meta Pixel / GA4 โหลดหลังกดยอมรับเท่านั้น
- หลังบ้านมี security header ครบและ `X-Robots-Tag: noindex`
- หน้า 404 คืน HTTP 404 จริง (ไม่ใช่ soft 404)
- ไม่มีลิงก์เสียเลยทั้งเว็บ (`build/linkcheck.js` รายงาน "ลิงก์เสีย 0")
- ไม่มี horizontal scroll ที่ความกว้างใดเลยใน 10 ขนาดที่ทดสอบ
- เทสต์ผ่านทั้งหมด: หน้าบ้าน 542 ข้อ · หลังบ้าน ประมาณ 4,345 ข้อ (0 ไม่ผ่าน)
