# แบรนด์ "ที่ดินชัวร์" (NJ TEEDINSURE)

โลโก้แบบ C — **โล่ + แปลงที่ดิน + ติ๊กถูก**

- **โล่** = ชัวร์ มั่นใจ ปลอดภัย
- **สี่เหลี่ยมเอียง + จุดสามมุม** = แปลงที่ดินและหมุดหลักเขต (งานรังวัด)
- **ติ๊กถูกเขียว** = ผ่านการรังวัดยืนยันแล้ว — จุดขายเดียวที่คู่แข่งลอกไม่ได้ เพราะต้องมีใบอนุญาตช่างรังวัดเอกชน

## วิธีสร้าง PNG ใหม่ถ้าแก้โลโก้

PNG ทั้งหมดสร้างจาก SVG ด้วยการวาดลง canvas ในเบราว์เซอร์ (ไม่ต้องลงโปรแกรมอะไร) —
ถ้าแก้ SVG แล้วต้องการ PNG ชุดใหม่ บอก Claude Code ได้เลย จะสร้างให้ใหม่ทั้งชุด

## สิ่งที่ต้องแก้เมื่อโดเมนจริงพร้อมใช้งาน
